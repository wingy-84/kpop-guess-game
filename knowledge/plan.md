# K-pop 猜歌網站計畫

## 願景

打造一個有趣、容易上手的 K-pop 猜歌網站，讓玩家透過不同類型的線索猜出歌曲或歌手。網站以輕鬆的遊戲體驗為主，讓玩家可以逐步獲得提示、作答並查看答案。

## 核心玩法

- **Emoji 猜歌**：根據一組 emoji 猜歌曲或歌手。
- **舞蹈動作猜歌**：根據舞蹈動作的文字線索猜歌曲。
- **MV 猜歌**：根據 MV 的畫面、場景或情節線索猜歌曲。

## 決策紀錄

- 初版使用純 HTML、CSS、JavaScript，無需建置程序即可由 GitHub Pages 提供靜態網站。
- 初版舞蹈與 MV 模式以文字描述呈現，避免依賴尚未確認授權的媒體素材。
- 每個模式以現有題庫長度作為一輪的題數；答對每題得一分，揭曉答案不加分。未加入倒數計時或保存跨輪最佳成績，維持即開即玩的簡單流程。
