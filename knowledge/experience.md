# 經驗紀錄

## 2026-11-26：以一輪完整遊戲建立計分與結算

- **做法**：每次開始遊戲時複製並洗牌該模式的題目清單，逐題更新「第幾題／總題數」與得分，答對加一分；看答案可以繼續遊戲，但不會加分。最後一題後顯示成績，提供重新挑戰；開始任何模式時重置回合控制項。
- **原因**：讓玩家知道遊戲何時結束，並讓答題結果有明確回饋。複製清單後再洗牌，避免更動原始題庫順序。
- **適用範圍**：無伺服器、題目預先放在 JavaScript 陣列的單頁問答遊戲；若要跨重新整理保存紀錄、多人排名或計時賽，需另加持久化或後端設計。
- **檢查重點**：逐一遊玩每個模式；確認答對計分、揭曉答案不計分、末題結算、重玩及結算後切換其他模式都正常。

- **額外發現**：開始功能測試前先執行 `node --check`，可快速抓出字串引號等解析錯誤；本專案曾有一則提示因英文撇號未跳脫導致整支腳本無法載入。
- **適用範圍**：不使用建置工具的原生 JavaScript 靜態網站，以及修改題庫字串或內嵌文案後的快速檢查。
