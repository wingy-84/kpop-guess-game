# GUESSPOP — K-pop 猜歌

以 Emoji、舞蹈動作和 MV 線索挑戰 K-pop 知識的輕量互動網站。以純 HTML、CSS、JavaScript 製作，透過 GitHub Actions 自動部署到 GitHub Pages。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## GitHub Pages 部署

將此專案推送到 `main` 分支後，GitHub Actions 會自動發布網站。第一次使用時，請在 Repository 的 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions** 作為來源。

## 遊戲模式

- Emoji 猜歌
- 舞蹈動作猜歌
- MV 場景猜歌
